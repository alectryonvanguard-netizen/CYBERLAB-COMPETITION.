# CYBERLAB

A mobile-first cybersecurity learning app built with Kotlin and Jetpack Compose.

## What is included
- Welcome experience and home dashboard
- Learning hub with guided beginner topics
- Safe, fictional practice simulations
- Knowledge-check interaction
- Progress, profile and settings overview
- Android APK build workflow using GitHub Actions

## Safety approach
CYBERLAB teaches defensive cybersecurity concepts. Its practice activities use fictional examples and local simulations; they do not scan, attack, or connect to real systems.

## Build
The project uses Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Java 17 and Gradle 8.9.
Run `gradle assembleDebug` to build the debug APK.
